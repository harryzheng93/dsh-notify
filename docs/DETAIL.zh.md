# 系统通知提醒

需要授权、或者一轮对话跑完时弹出 Windows 通知，点通知把应用窗口拉回前台。

## 你会看到什么

- **需要授权**：正文用请求方给的本地化说明，没有说明就显示工具名。
- **本轮完成**：会话从运行中停下来时提醒。

授权那条只是提醒，请求照常进入界面里的授权卡片，做决定仍然是你。相同内容在两秒内
不会重复弹。

## 它是怎么做到的

未打包的应用要弹 toast，必须用一个已经在开始菜单快捷方式里注册过的应用标识来创建；
DeepSeek Harness 从来没有设置过，所以页面里造出来的通知会被系统接受然后丢弃。
这个插件改在宿主进程这侧，用快捷方式已经注册的身份通过 Windows PowerShell 直接发
toast，并把点击动作指向应用自己的 `dsh:` 协议。应用持有单实例锁，所以点通知是把已经在
跑的窗口唤到前台，而不是再开一份。

## 配置

在 `cordis.patch.yml` 这一行的 `config` 下，全部可选：

- `aumid` —— 发通知使用的应用标识，默认 `electron.app.DeepSeek Harness`。
- `launch` —— 点击时激活的地址，默认 `dsh://open`。
- `language` —— `zh`、`en` 或 `auto`；默认 `auto`，跟随宿主语言。
- `debug` —— 在临时目录写 `dsh-desktop-notify.log`，记录每次事件和 PowerShell 退出码。

## 已知限制

- 只支持 Windows；其它平台加载后什么也不做。
- 每一轮结束都提醒，窗口在前台也提醒。
- 子代理的轮次也会提醒，宿主侧分辨不出子代理会话和普通会话。
- 换了安装名或应用标识，需要改 `config.aumid`。
- 没有界面；要关闭就在「设置 → 插件」里禁用。
